## 🚀 Install

**Quick install (always latest):**

```bash
curl -fsSL https://install.pwahub.org/bootstrap.sh | sudo bash
```

![Ubuntu](https://img.shields.io/badge/Ubuntu-20.04_|_22.04_|_24.04_|_26.04-E95420?logo=ubuntu&logoColor=white)
![Debian](https://img.shields.io/badge/Debian-12_|_13-A81D33?logo=debian&logoColor=white)
![Arch](https://img.shields.io/badge/arch-x86__64_|_aarch64-555?logo=linux&logoColor=white)

Before installing, check the [requirements](https://docs.pwahub.org/guide/requirements),
then follow the [installation guide](https://docs.pwahub.org/guide/install) and
[quick start](https://docs.pwahub.org/guide/quickstart).

## 📦 Container images

All images live under `ghcr.io/pwahub-org/*` and pull anonymously:

| Image | Purpose |
|-------|---------|
| `ghcr.io/pwahub-org/core`    | Backend - HTTP + workers |
| `ghcr.io/pwahub-org/app`     | Admin frontend |
| `ghcr.io/pwahub-org/client`  | Client frontend |
| `ghcr.io/pwahub-org/tds`     | Traffic distribution |
| `ghcr.io/pwahub-org/landing` | Landing pages |
| `ghcr.io/pwahub-org/filter`  | Traffic filter |
| `ghcr.io/pwahub-org/traefik` | Reverse proxy |
